# MiitStream for Windows

**Download:** open [the latest release](https://github.com/Miitcryo/MiitStream-releases/releases/latest) and download `MiitStream-Setup-<version>.exe`.

The first time, Windows may say "Windows protected your PC". Click **More info › Run anyway**. The app updates itself after that.

---

**تحميل:** افتح [آخر إصدار](https://github.com/Miitcryo/MiitStream-releases/releases/latest) ونزّل `MiitStream-Setup-<version>.exe`.

أول مرة ممكن ويندوز يقول "Windows protected your PC". اضغط **More info** وبعدها **Run anyway**. بعدها التطبيق يحدّث نفسه.
